Local demo: open this page through a tiny web server from the repository root (so the browser can load the GeoJSON). Example: cd /path/to/PGE && python3 -m http.server 8765 then visit http://localhost:8765/web/wfigs_incidents_or_wa.html. Regenerate: python3 scripts/wfigs_incident_locations_fetch.py --user-agent "…" then python3 scripts/wfigs_nearest_transmission.py (map + table; adds NRI WFIR_RISKR when the point falls inside web/NRI_Census_Tracts_PGE.geojson).

Transmission lines from data/wildfire/transmission_lines_wgs84.geojson (exported by wfigs_nearest_transmission.py). PGE service area on the map: census tracts from web/NRI_Census_Tracts_PGE.geojson (≈60% transparent fill). Tiles: OpenStreetMap. Nearest transmission line table is below the map (from JSON). NRI tract WFIR_RISKR is joined when the point lies inside web/NRI_Census_Tracts_PGE.geojson; otherwise the table cell is blank. Also: CSV, Markdown. Regenerate: python3 scripts/wfigs_nearest_transmission.py (GDAL osgeo + ogr2ogr on PATH). Not an official evacuation or operations map — decision support only; follow NIFC Open Data terms.
