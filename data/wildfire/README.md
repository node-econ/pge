# Wildfire data products (generated)

Files in this directory are **regenerated by scripts**, not hand-edited.

| File | Generator |
|------|-----------|
| `wfigs_incident_locations_or.geojson` | `python3 scripts/wfigs_incident_locations_fetch.py` |
| `wfigs_incident_locations_or.meta.json` | same (sidecar metadata) |
| `incidents_nearest_transmission.csv` | `python3 scripts/wfigs_nearest_transmission.py` (after fetch; needs GDAL `osgeo`) |
| `incidents_nearest_transmission.md` | same |
| `incidents_nearest_transmission.json` | same (for embedded table on `web/wfigs_incidents_or_wa.html`) |
| `transmission_lines_wgs84.geojson` | same (`ogr2ogr` → WGS 84 for the demo map line overlay) |
| `ignitions_spread_model_handoff.md` | `python3 scripts/wildfire_ignitions_spread_handoff.py` (after nearest-transmission JSON) |

**Source:** NIFC WFIGS **Current Incident Locations** (public ArcGIS Feature Service). See [`docs/wildfire_rapid_assessment.md`](../../docs/wildfire_rapid_assessment.md) for attribution, WindNinja / ELMFIRE context, and operational caveats.

Optional CSV for a briefing board:

```bash
python3 scripts/wfigs_incident_locations_fetch.py \
  --csv-out data/wildfire/wfigs_incident_locations_or.csv
```

Narrow to a bounding box (WGS 84) after fetch:

```bash
python3 scripts/wfigs_incident_locations_fetch.py \
  --bbox -125.0,41.9,-116.0,46.5 \
  -o data/wildfire/wfigs_incident_locations_bbox.geojson
```

## Demo map (local)

Leaflet page: [`web/wfigs_incidents_or_wa.html`](../../web/wfigs_incidents_or_wa.html). From the **repository root**:

```bash
python3 scripts/wfigs_incident_locations_fetch.py --user-agent "YourOrg/1.0 (you@example.com)"
python3 scripts/wfigs_nearest_transmission.py
python3 -m http.server 8765
```

Then open `http://localhost:8765/web/wfigs_incidents_or_wa.html` in a browser (required so `fetch` can read `../data/wildfire/…`).

**Spread model handoff:** [`docs/wildfire_ignition_spread_model.md`](../../docs/wildfire_ignition_spread_model.md) — then `python3 scripts/wildfire_ignitions_spread_handoff.py` → `ignitions_spread_model_handoff.md`.

## Nearest transmission line

```bash
python3 scripts/wfigs_nearest_transmission.py
```

Produces **`incidents_nearest_transmission.csv`** and **`.md`**: each Oregon incident with optional **WFIR_RISKR** (when the point is inside the NRI PGE tract layer) and distance to the closest line in `spatial/Transmission_Lines.shp`. See [`docs/wildfire_rapid_assessment.md`](../../docs/wildfire_rapid_assessment.md) §1b.
